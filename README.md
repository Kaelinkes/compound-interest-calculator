# compound-interest-calculator

A basic compound interest calculator written in Java.

This project demonstrates my early learning of Java fundamentals, including:

- Using Scanner to accept user input
- Performing mathematical calculations with Math.pow()
- Formatting output using printf
- Working with variables and basic data types

The program calculates the final amount based on principal, interest rate, compounding frequency, and number of years.
Input validation is not implemented yet, but this will be improved as I continue learning Java
